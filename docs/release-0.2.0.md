# v0.2.0 — executable calibration release

Maintained by Maxime Sebti as an independent research project.

Adds an installable CPU evaluator, portable contracts, trusted adapter interface, depth-format bridges, original analytic scenes, three controls, world-level/paired intervals, raw-evidence replay, visual/JSON/CSV reports, CI and a results browser. Current project metadata uses individual authorship; the v0.1 tag remains historical.

Scoring is offline and array-based. Tasks: spatial views, camera-Z depth, return-view consistency, fixed-camera appearance editing and future frames. Pixel/depth diagnostics are not a validated perceptual or physical intelligence score. Calibration scenes are public and analytically simple.

No external datasets, model weights, upstream benchmark results or learned-model scores are bundled. Output bridges do not imply model execution. A hidden test set, secure inference service, live ten-frame commitment service and stateful engine qualification are not supplied by this release.

CI retains generated development evidence and separate-runner replay records. They establish reproducible software checks, not review by an unaffiliated scientist. Release assets preserve package and calibration evidence for longer-term replay.
